# 스마트홈 Troubleshooting 인덱스

_이미 해결한 문제를 증상 키워드로 찾아 같은 조사를 반복하지 않도록 합니다._

---

## 🔍 검색 순서

1. 증상과 오류 문자열로 이 폴더를 검색한다.
2. 문서의 적용 조건과 현재 환경이 같은지 확인한다.
3. 과거 해결책을 적용하기 전에 현재 상태를 읽기 전용으로 재검증한다.
4. 원인이 다르면 기존 기록을 억지로 재사용하지 말고 새 항목을 만든다.

## 📋 항목 목록

| ID | 증상 | 근본 원인 | 해결 |
| --- | --- | --- | --- |
| T-001 | HA UI가 8123에서 열리지 않음 | 새 Supervisor 설치가 포트 80 사용 | 80·8123·4357을 분리 검사 |
| T-002 | `git push`가 사용자명을 읽지 못함 | 비대화형 HTTPS 인증 부재 | 로컬 커밋 보존 후 GitHub MCP 사용 |
| T-003 | HAOS 콘솔이 오래 멈춘 것처럼 보임 | NEM snail mode 또는 guest-agent 대기 | 시간과 포트를 함께 확인 |
